# Contributing

Thank you for your interest in improving this project. Contributions should make the analysis more reproducible, understandable, and responsible.

## Before opening a pull request

Please explain the problem being solved, identify any data or modeling assumptions, and keep secrets and private datasets out of commits. For model changes, include the evaluation metric, validation approach, and a short note on limitations.

Small documentation, testing, and reproducibility improvements are welcome. Please use a focused branch and keep unrelated changes separate.

## Pull request checklist

- The README and relevant documentation have been updated.
- The project still runs from a clean environment or the limitation is documented.
- Tests or validation steps have been run where applicable.
- No credentials, personally identifiable information, or restricted datasets are included.
- Financial outputs are clearly labelled as educational research, not investment advice.
