# Security Policy

Please do not disclose credentials, private datasets, personally identifiable information, or exploitable details in a public issue.

For a sensitive concern, open a minimal issue requesting private contact or use GitHub's private vulnerability reporting if enabled for this repository. Rotate any credential that may have been exposed and remove it from the active configuration immediately.

This project is an educational research portfolio. It does not provide investment advice, trading instructions, or guarantees of financial performance.
